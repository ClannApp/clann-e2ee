Clann E2EE Inspector

Opens a Clann encrypted file on this computer using only your browser's built-in crypto. This is one file with no libraries, and its security policy blocks network requests, so you can read the source and run it offline.

This browser isn't offering WebCrypto here, so nothing below will work. Try a current version of Chrome, Firefox or Safari.

Ideally one you got yourself, by capturing the upload or download. The format is CLN1, described in PROTOCOL.md.

In the app, open the photo, tap the ⋯ menu, then What Clann sees, then Get this memory's key. It's a secret: anyone with the key and the file can open this memory in every stored size. This page doesn't save or send it.

Upload this instead of a family photo. Its random ID lets you match the original, the stored file and the recovered image, even after the app re-encodes it.
